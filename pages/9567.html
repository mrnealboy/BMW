Dealing With Short Circuits In the Footwell Module, FRM



Dealing With Short Circuits In The Footwell Module, FRM

NOTE: A total of 4 short-circuit faults can be stored in the control unit.

Description:
If a short-circuit is detected in a power circuit, this power circuit is switched off after one minute. This power circuit remains switched off until there has been a terminal change (terminal 15 - terminal 30 - terminal 15).
A renewed attempt to switch on is only made after a terminal change.
The footwell module permanently switches off the corresponding output if a total of 50 terminal changes have taken place while there is a short-circuit in a power circuit. This is the case if, despite repair of the short circuit, the fault code memory entry can no longer be deleted.
In this case, the footwell module must be replaced.
