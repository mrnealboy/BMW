Procedure For Commissioning or Adjusting the Active Steering (AL) (AL active front steering (AFS70))



Procedure For Commissioning Or Adjusting The Active Steering (AL)

The service function Commissioning/Adjusting active steering must be run during or after the following work:
- work on the steering column
- after replacing the active steering control module (AL)
- after replacing the steering column switching centre (SZL):
- on calibration of the steering-angle sensor
- after replacing the steering gear

The sequence for Commissioning/Adjustment in the service function is as follows:
- Possibility to set the wheel steering angle exactly to zero for any axle alignment/wheel alignment. A precondition for this is a valid steering angle sensor value (SZL) and engine location angle (AL). Choice of calling up (see Note)
- Check of the validity of the steering angle sensor value. If the steering-angle sensor has only lost its revolutions, possibility of restart by steering from limit position to limit position.
- Reset the engine location angle (AL)
- Steering-angle sensor adjustment (optional; it is decided in the service function whether this is necessary or not)
- Clear DSC fault memory (only for steering-angle sensor adjustment)
- Calibrate the engine location angle (AL)
- Clear AL fault memory
- Possibility to preset the wheel steering angle exactly to zero for wheel alignment after successful commissioning / adjustment of the active steering. Choice of calling up (see Note)

NOTE:
Only perform axle alignment/wheel alignment if:
- The diagnosis of the active steering leads to no defect (no fault memory entry) and there is a deviation in the position of the steering wheel
- The guided troubleshooting with fault memory entry 'active steering' concludes with the defect 'Wheel alignment'
- Repair measures are carried out that make axle alignment/wheel alignment necessary (see corresponding repair instructions)

In the case of an inclined steering wheel and diagnosis of active steering without result:
- Check the steering-wheel angle (see control-module functions); in the exact centre steering wheel position it must show 0° ( ± 2°); if it does not, run commissioning / adjustment of the active steering with steering-angle sensor adjustment
- Check the total steering angle for active steering (see control-module functions); in the exact centre steering wheel position it must show 0° (± 5°); if it does not, run commissioning / adjustment of the active steering without steering-angle sensor adjustment
- Perform wheel alignment and adjust if necessary
