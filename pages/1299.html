Mechatronics Of The Automatic Gearbox

The mechatronics in the 6HPTU/8HP electronic automatic transmission consists primarily of the electronics module and the hydraulic unit.

Electronics module
The electronics module is divided mainly into the following components:
- EGS control unit
- Voltage supply for solenoid valves and electronic pressure control valves
- Gearbox sensor system:
- Sensor for transmission input speed
- Sensor for the gearbox output speed
- Gearbox oil temperature sensor

- Gearbox connector for connection to vehicle wiring harness

EGS control unit
The EGS is installed as part of the gearbox with the 6HPTU/8HP gearbox. It evaluates the sensors electronically and directly activates the actuators of the hydraulic module. A temperature sensor of the EGS processor additionally monitors the gearbox oil temperature.

Hydraulic module
The hydraulic module is similar to the modules used so far in gearboxes. It is designed as holder for the electronics module.
