Antitheft and Alarm Systems: Description and Operation



Antitheft Alarm System (DWA)

The DWA electronics are integrated in the following control units:
- Saloon, Coupe and Touring: Control unit, interior protection
- Convertible: Control unit for siren with tilt sensor

The DWA (anti-theft alarm system) electronics evaluate the signals relevant to the alarm system and decide whether the alarm should be triggered. The control unit is connected to the data bus K-CAN SYSTEM, across which it receives the signals of the CAS, junction box electronics and footwell module control units.
In the convertible, an additional separate DWA data bus is connected at the siren with tilt sensor control unit. The signals between the DWA electronics and microwave sensors are transferred across this data bus.

DWA alarm activations
The last 10 alarm activations are stored in the DWA alarm memory.
To read out the DWA alarm memory in the function and component selection, select the line "DWA activations" and start the test module.

Customer complaint - false alarm
Procedure in the event of the customer complaint 'false alarm':
- Read out the DWA alarm memory (test module 'DWA activations').
- Check all the sensors that caused an alarm.
- During the check, take account of the fact that a mechanical fault can also be responsible alarm (example: engine compartment lid, door or luggage compartment lid does not close
