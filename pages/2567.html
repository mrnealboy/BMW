General Notes On The Diagnosis Of Customer-Initiated Software Updates

General notes on the diagnosis of customer-initiated software updates (KISA)
The KISA function is used to update the control unit. A customer-initiated software update may, for example, resolve restrictions in mobile phone compatibility or improve the usability of functions. The software updates can be installed by connecting a USB stick with the updates stored on it and selecting KISA from the Central Information Display. Possible installation faults for customer-initiated software updates are listed in procedure [Check telecommunications system] under KISA. Therefore the appropriate measures are taken from the stored information for the functional description.

Observe the following notes on using USB devices:
- If a USB device does not work in the vehicle, connect the USB device to a PC and check whether the device is correctly detected there.
- For the KISA function, the USB device must be connected to the USB port in the centre console. A KISA is not possible via the connection in the glove box.
- The USB device must be configured as a Mass Storage Device.
- USB devices with a high power consumption, e.g. USB hard disks, cannot be used.
