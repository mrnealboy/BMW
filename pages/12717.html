Roll Bar: Description and Operation



Rollover Protection System

There is a roll bar behind each of the rear seats. During normal operation, the roll bars are inserted in the carrier structure and are held in place by a retainer. The retainer is controlled by the rollover protection controller by means of an electromagnet. The electromagnet activates the retainer and releases the spring-loaded roll bar.

Rollover protection controller
The rollover protection controller
- monitors itself internally.
- is not directly diagnosis-capable.
- is connected across a serial cable with the airbag control unit.
- in the event of a fault it sends a message to the airbag control unit, at the same time creating a fault code memory entry.

Roll bar
In the event of an accident with rollover, the sensor in the airbag control unit detects the vibration and sends the information "activate roll bar" to the rollover protection controller.

There are three possibilities to activate the roll bar:
- Activation in the event of an accident
- Activation for verification of function via diagnosis (service functions)
- Activation by mechanical emergency release process (if not possible via diagnosis)

To return the triggered roll bar to the initial position, the toothed strip must be turned back. In doing so, the safety regulations in the repair instructions must be taken into account.

Trigger the roll bar
- Before triggering the roll bar, open the convertible top.
- On activation of the roll bar, no persons may be located in the immediate vicinity.

NOTE: All work on the airbag must only be conducted with the battery disconnected.Connect and disconnect airbag control unit, sensors and gas generators only with the battery disconnected.The airbag control unit contains vehicle-specific data and must therefore be encoded before placing into operation. Removal and installation in other vehicles is prohibited.
