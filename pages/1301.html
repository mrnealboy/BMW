Transmission Adaptation On The GM6 Automatic Transmission

With the service function 'transmission adaptation', a number of test are carried out so that the transmission control can store various characteristic data of the transmission:
- Fill time
- Amplification
- Deviation

As soon as the clutch data is stored, it is written at the end of the transmission adaptation in adaptive data cells of the transmission control. These data cells are used by the transmission control for clutch control during gearshifts.

The transmission adaptation must be carried out after the following tasks:
- Replacing the mechatronics
- Replacing the transmission control module
- Replacing the hydraulic selector unit
- Programming the transmission control module

The service function 'transmission adaptation' for the most part automated.

The instructions of the BMW diagnosis system must be followed without fail, as this is the only to ensure a correct operation.

NOTE: The temperature range in which the service function 'transmission adaptation' must be run is 70 - 95 °C. The fault code memory of the transmission control must be free of faults (no permanent fault in the fault memory).
