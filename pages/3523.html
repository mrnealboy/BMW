Symptom Related Diagnostic Procedures



Instrument Cluster: Power Supply Switched Off

Symptoms:
- The time and date in the instrument cluster and in the Central Information Display are lost.
- The fault code memory entry "instrument cluster: power supply switched off" is stored in the instrument cluster.

Cause:
The fault code memory entry does not indicate a defect in the instrument cluster or in the power supply of the instrument cluster, rather only disconnection of the power supply of the instrument cluster by the KGM: reset or cut off terminal 30g-f.
Reset or cutoff of terminal 30g-f is due to a fault in the vehicle: too many wakings with terminal R Off, closed-circuit current fault, sleeping inhibited, reaching the starting capability limit.

Procedure:
If there is an impairment (e.g. time was lost; see above symptoms), the test module 'Energy diagnosis' helps in finding the cause of the problem in the vehicle energy system: run the test module.
If the vehicle had a breakdown due to a flat battery despite the reset or cutoff of terminal 30g-f, it is usually the case that the control units supplied via this terminal are not the likely cause.
