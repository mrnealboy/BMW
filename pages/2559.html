Voice Activation System: Testing and Inspection



Loss Of Voice Control

The application of so-called enable codes for Sweeping Technologies means that components and special functions can be linked to a vehicle. It is not possible to use and activate the functions without enable codes. If the vehicle has to be programmed with Progman V 25.0 or higher and the CCC is listed in the measures plan, an enable code must be imported. If the enable code is not imported during the session and processing of the measures plan continues, function changes that the customer can experience occur. In the case of the Car Communication Computer (CCC), optional extra 620 (extended voice control) is no longer available. Enabling has already been carried out at the plant. As the enable code is not on the DVD for Sweeping Technologies, it can only be ordered via the EPC.

Importing the enable code in Program:
1. After display in Progman [The following enable codes are to be imported x Code x not imported] activate the [Import] button.
2. After the display [Please insert the data medium with enable codes], place the DVD with the enable codes in the drive of the SSS and activate the [Next] button.
3. The display [The following enable code files are to be imported x Code x imported.] appears again. Now activate the [Import end] button.
4. Processing the measures plan is continued. If the enable codes cannot be imported and processing of the measures plan still continues, function changes that the customer can experience occur.

The extended voice control (optional extra 620) might no longer be available after, among other things, programming with Progman Version 25.0 and higher. Processing the measures plan is not influenced. Importing the enable code can be repeated later in a new Progman session via the [Load SW] button.

If enabling per DVD for Sweeping Technologies fails, the enable code for all vehicles can be ordered via the EPC. Following the order, the enable code is available as a ZIP container (compressed data format) for download in the After Sales Assistance Portal (ASAP). The ZIP container contains three files that have to be unpacked on a floppy disk or CD.

Once the data storage medium can be inserted in the SSS, the import can be carried out as described at point 1.
The operation for the download in the ASAP is described there. If you have any questions, please contact Technical Support in your market.
