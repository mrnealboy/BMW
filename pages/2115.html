Multiple Restraint System (MRS)



Multiple Restraint System (MRS)

NOTE: All work on the airbag must only be conducted with the battery disconnected. Connect and disconnect control unit, sensors and inflator assemblies (gas generators) only with the battery disconnected. The MRS control unit contains vehicle-specific data and must therefore be encoded before start-up. Removal and installation in other vehicles is prohibited.
