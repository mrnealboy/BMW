63 99 072 Replacing Halogen Bulb For Left (Or Right) Headlight







WARNING: Follow instructions for handling light bulbs (exterior lights).







NOTE: Headlight (2) removed for purposes of clarity.

Unlock spring wire clips (1) in direction of arrow.
Remove cover from headlight (2).

Installation note:
Make sure cover is correctly seated on headlight (2).

Guides (3) must be exactly seated in associated locators (4).
Check seal.
Replace cover, if necessary.
Comply with instructions for replacing the cover.







Disconnect plug connection (1).
Disengage spring wire clip (2).
Remove bulb (3) towards rear from headlight (4).

Installation note:
Make sure bulb (3) is exactly seated in headlight (4).
Note bulb type.
