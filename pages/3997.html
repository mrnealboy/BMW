A - Control Units, Modules




A: Control units, modules






The illustration shows the DME control unit "A6000" for the engine N52 in the E90. (DME: digital engine electronics). In the background is the circuit diagram for this abbreviated designation.

Note: Control units in abbreviations index
Many control units have already been listed in the SBT (SI Technology bulletin) "Abbreviations" .
Please refer to section "Abbreviations of control units in diagnosis and programming".
These control units can be encoded and programmed.
These control units appear in the quick test in the BMW diagnosis system (depending on vehicle equipment).
[For more information, please refer to SI Technology (SBT) 000103035_B04]
This list contains all BMW control units with the abbreviated designation "A..." (regardless of whether or not the control units concerned appear in the quick test or in programming).

Note: Abbreviations of control units in quick test
Control units with an abbreviation can be found in the quick test in the BMW diagnosis system and in Progman. These abbreviations can be found in the column headed "Information" in the table below.
Each control unit with an abbreviation appears in the quick test.
Control units without their own abbreviation are diagnosed via the master control units. These control units may also be self-diagnosable but transmit any fault memory entries to the master control unit concerned. The BMW diagnosis system reads off these fault memory entries from the master control unit.

Note: Some abbreviated designations only for technical reasons associated with the system
Some abbreviated designations not only stand for components, but also for other descriptions in the circuit diagram. For example, "A30" for "Terminal 30" in the circuit diagram "Radio/stereo" for the E52. Or the abbreviated designation "N52" - as a rule an engine model.
This abbreviated designation is also contained in this glossary for the sake of completeness.

Note: Cross-references between abbreviated designations
Some abbreviated designations and components have the same function or belong to similar systems. However, for technical reasons associated with the system "Hotspots", i.e. electronic cross-references are not possible within the glossary.
To highlight the interrelationships between components and to save the reader from frequent repetitions with similar contents, cross-references have marked as follows:
"-> see A123" means: The information concerning this abbreviated designation also applies to component A123.
"-> A123" at the end of the information refers to a further component from this system.
