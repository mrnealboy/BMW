00 00 624 Service - vehicle check

- Service - vehicle check

- Diagnosis brief test (not US)
- Check horn, headlight flashers and hazard warning flashers
- Check instrument and inscription lighting and blower
- Check lighting system
- Seat belts: Check condition of seat belt strap, function of automatic reel, seat belt locking reel and seat belt buckle
- Check windscreen wash/wipe system
- Convertible only:
Trigger rollover protection system (Convertible) via diagnostic interface. Warning: open soft top first
- If available: (M) Mobility System: Check expiry date on sealant bottle, replace sealant bottle if necessary
- Body: Check for corrosion (except cavities)
- Tires: Check tread depth, tread wear pattern, external condition and tire pressure and correct if necessary (spare wheel as well)
- Initialize Run Flat Indicator
- Check battery (magic eye), if necessary recharge battery (issuing a separate invoice for this work)
- Check display (magic eye)
- If necessary: Charge battery
- Steering fluid reservoir: Check oil level.
- Checking coolant level and concentration, topping up if necessary
- Windscreen washer system: Check fluid level, top up if necessary
- Brake lines and connections: Check for tightness, damage and correct position
- Floor plate incl. all visible components: Check for damage, tightness, corrosion
- Steering components: Check for play, tightness, damage and wear
- Check road safety (test drive):
- Brakes
- Steering
- Shock Absorbers
- Transmission
- Reset CBS display according to factory specification
