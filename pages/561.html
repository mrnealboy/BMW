Exhaust System: Service and Repair




18 00 020 - Removing and installing/replacing complete exhaust system (N52/ N52K/ N51)





Special tools required:
- 31 2 220





Warning!
Scalding hazard!

These tasks should only be carried out on an exhaust system that has cooled down.





Important!
Removal of the exhaust system must be carried out with the assistance of a second person.





Necessary preliminary tasks:

- E91/ E92/ E93/ E82/ E88 only:Remove tension strut on rear axle.





Support exhaust system with jack and special tool 31 2 220 and secure against falling out.





Unscrew nuts.

Installation Note:
Replace self-locking nuts.

Replace seal.

Tightening torque 18 20 1AZ 18 20 Exhaust System Suspension.





Release bolt and remove bracket (1).

Installation Note:
Tightening torque 18 20 2AZ 18 20 Exhaust System Suspension.





Unfasten screw connection.

Installation Note:
Tightening torque 18 20 3AZ 18 20 Exhaust System Suspension.





Unfasten nut.

Installation Note:
Tightening torque 18 20 4AZ 18 20 Exhaust System Suspension.





Release screw on right bracket.

Installation Note:
Tightening torque 18 20 5AZ 18 20 Exhaust System Suspension.





Release bolts along line and remove reinforcement plate (1).

Lower exhaust system and remove.





Installation Note:
Check exhaust system for leaks.
