Garage Door Opener Transmitter: Testing and Inspection



Setting The Garage-Door Opener

The integrated universal remote control fitted in the interior mirror replaces up to three different hand-held transmitters of various radio-remote-controlled facilities, such as gate openers and house alarm systems. The integrated universal remote control detects and learns the sent signal from each original hand transmitter. The signal of an original hand-held transmitter can be programmed onto one of the three memory buttons.
Subsequently, the memory button programmed in this way can be used to operate each facility. Transmission of the signal is indicated by the LED.

Preconditions
The radio-remote-controlled facility must be compatible with the integrated universal remote control. If the compatibility cannot be determined, see 4.

NOTE: During the programming procedure and before every remote activation of a programmed facility using the integrated universal remote control, ensure that no persons, animals or objects are within the swing or movement range of each facility, as otherwise injuries or damage can be caused. Also comply with the safety instructions for the original hand-held transmitter.

1. Programming (fixed-code hand-held transmitters)
1. Switch on ignition
2. On commissioning: Press both of the outer memory buttons for approx. 20 seconds until LED 2 flashes. The three memory buttons have been deleted.
3. Hold the original hand-held transmitter at a distance of approx. 10 to 30 cm from the memory buttons. The required distance between the hand-held transmitter and memory buttons depends on the system of the original hand-held transmitter that is used.
4. Press the send button of the original hand-held transmitter and the desired memory button of the integrated universal remote control simultaneously. Initially, the LED flashes slowly. When the LED begins to flash rapidly, let go of both buttons. If the LED does not flash rapidly after approx. 15 seconds, change the distance.
5. To program other original hand-held transmitters, repeat steps 3 and 4.

The corresponding memory button is now programmed with the signal of the original hand-held transmitter. The facility can now be operated when the ignition is switched on.
If the facility cannot be used after repeated programming, check whether the original hand-held transmitter is equipped with a random code system. Determine this either by reading the instructions for the original hand-held transmitter or by pressing the programmed memory button of the integrated universal remote control for a longer period. If the LED of the integrated universal remote control flashes for a short time and then lights up constantly for approx. 2 seconds, the original hand-held transmitter is equipped with a random code system. In the case of a random code system, program the memory buttons as described at 'Programming (random code hand-held transmitter).

2. Programming (random code hand-held transmitter)
To program the integrated universal remote control, use the operating manual of the equipment to be set. Obtain information there regarding the possibility for synchronization. When programming a random code hand-held transmitter, comply with the following additional instructions:
1. Park the vehicle within range of the radio-remote-controlled facility
2. Program the integrated universal remote control as described previously at 'fixed-code hand-held transmitters'.
3. Find the button on the receiver of the equipment to be set, e.g. on the drive.
4. Press the button on the receiver of the equipment to be set. After Step 4, approx. 30 seconds remain for Step 5.
5. Press the programmed memory button of the integrated universal remote control three times.

The corresponding memory button 1 is now programmed with the signal of the original hand-held transmitter.

3. Deleting stored programs
Press both of the outer memory buttons for approx. 20 seconds until the LED flashes. All of the stored programs are deleted. Individual memory buttons cannot be deleted.

4. Help
