CCC Tips And Tricks

Diagnosis CCC - Tips and Tricks

Control unit functions

ANT / Aerial Tuner
- Aerials self-test
In the control unit functions, the aerials self-test has to be started before the result can be requested. Otherwise the function aerials self-test always returns an OK.

- Switching diversity to individual aerials only delivers the right result after an aerials self-test.

CCC-GW / gateway
- Diagnosis of fan speed
In order to obtain a correct result when querying the fan speed, you must wait at least 10 seconds between fan activation and querying the speed. During this time, the fan accelerates to the given speed. The activation time of the fan is 30 seconds.

ASK / Audio System Controller
- Diagnosis request microphone test
Start microphone test by pressing Display.
As soon as the beeping tone stops, deactivate the diagnosis request by pressing Display again.
If the test returns not connected as its result, start the test once again and make "noises" towards the vehicle microphone during the beeping tone. The same applies if a Top HiFi amplifier is fitted in the vehicle, as in this case no beeping tone can be generated.
If this is not successful either, check the coding and correct if necessary.
If the coding is correct and the result is still not connected, check the connection of the vehicle microphone to the CCC according to the connection scheme and replace the vehicle microphone if necessary.

A / application
- Diagnosis requests ECE Navigation
If error messages of the tester occur during requests, the cause is probably a defective HIP module or a defective connection to the HIP module.

- Diagnosis request voice output
The default value for ECE and US is: ready.
The standard value for Japan is:not ready.

- Diagnosis request language recognition
The default value for ECE and US is: ready.
The standard value for Japan is: not ready.

Fault patterns
- In the "Diagnosis fault pattern selection" at "6500 Audio, video navigation", there is the item "650006 CCC: malfunction". This is where all the currently known fault patterns depending on the software version of the CCC are described.

Reset CCC
When the rotary pushbutton as well as the buttons CD/MD eject and DVD eject on the front panel are pressed simultaneously, the CCC runs a reset. Run according to the instructions in the test plan.

DVD/CD can no longer be removed from the drive
Reset the CCC. Directly afterwards, press the eject button until the DVD/CD is ejected. (This does not always work.)

Service menu
The Service menu is called up as follows:
- Select the start menu.
- Press the controller for approx. 15 seconds, then let go.
- Turn the controller three positions to the right.
- Turn the controller three positions to the left.
- Turn the controller one position to the right.
- Turn the controller one position to the left.
- Turn the controller one position to the right.
- Press the controller
