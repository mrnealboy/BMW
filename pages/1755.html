Note On Functional Description (AFS)

Diagnosis instructions
Commissioning/alignment of the active steering is necessary during or after the following work:
- After work on the steering column
- after replacing the active steering control unit
- after replacing the steering column switch cluster (SZL):
- on calibration of the steering angle sensor
- after replacing the steering box

Here, select the service function Commissioning/Alignment active steering and work through it (automated procedure).
The function can be found at the following path: Service functions/Chassis and suspension/Active steering
