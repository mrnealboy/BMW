General Information Regarding the Check

Notes on operation
The test module guides the user step by step through a fault tree. On the basis of fault lists (display in the left-hand display screen half) or a fault selection (display in the test module), the faults present in the vehicle can be determined. After entering the fault code, there is a branch to the next test step or the matching repair measure is displayed.

In addition to the repair measure, a diagnosis code is also displayed, containing the result of the test. This code enables statistical evaluation of the diagnosis reports transferred via FASTA (Vehicle Operation and Service Data Transfer and Analysis).

Please always run the test module up to the end.
