Fault Patterns For Central Information Display

On the Central Information Display, fault patterns that are not registered by fault code memory entries can occur alongside the possible fault code memory entries. The following table lists the most frequent fault patterns. The appropriate measure for fault elimination is described in the test module. Select the fault pattern from the list and enter the corresponding number.

Opening/closing


No. Symptom
001 The screen remains closed with terminal R switched on
002 Screen does not open completely
003 The screen closes and opens again of its own accord
004 Screen folds out of its own accord
005 Screen does not close
006 Screen twitches a number of times


Image construction


No. Symptom
101 Screen remains dark after opening
102 Screen is black for a brief period
103 Image display incomplete
104 Implausible image display / content with terminal R switched on
105 Poor contrast / colour cast
106 Picture is blurred / visually distorted

Background lighting


No. Symptom
401 Image only brightens slowly after terminal R switched on

Noise

No. Symptom
601 Screen rattles on folding out
