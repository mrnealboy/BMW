Initialize Power Windows



Initialize Power Windows

A window crank must be initialized to make sure that the anti-trap mechanism works in a trouble-free manner. Window cranks without an anti-trap mechanism cannot be initialized.
An anti-trap mechanism is always present if the window can be closed in automatic mode (toll function). There are then additional sensors in the power window drive that can record the position of the window in question. No antitrap mechanism is required for the "window open" automatic mode.

Initialize power windows
On initialization of the power windows, two parameters are learned by the control unit:
- Upper end stop (normalization of the power windows).
- Power characteristic curve for opening and closing (learning the characteristic curve).

A power window is to be initialized:
- In the event of malfunctions, e.g. no one-touch function (automatic mode) possible for closing, no convenient closing possible, window reverses without anything being trapped
- Following the replacement of the power window drive
- Following repair work on the window seals or power-window mechanism
- Following the replacement or reprogramming of the control unit

Preconditions
The following preconditions must be met to ensure initialization can be carried out correctly:
- Vehicle stationary.
- Adequate battery voltage present, connect charger is necessary.
- Terminal "R" or terminal "15" switched on
- All doors closed.

The initialization can be carried out using the control switch in each door or the power-window switch block in the driver's door.
In addition, the initialization can also be carried out with the service function "Initialize power windows".

Deleting the initialization (de-calibration)
Deleting an initialization (de-calibration) and subsequent re-initialization can remedy sporadic incorrect shutdowns in the power window automatic mode (toll mode).

Execution with operating switch
Open the window of each door completely. Press and hold in the operating switch completely (switch position: automatic mode) for longer than 15 seconds and less than 20 seconds
De-calibration was successful when the automatic mode (toll function) is no longer possible for the "Close window" function.

Execution of initialization via operating switches
The re-initialization is carried out as follows:
- Fully close the window by pulling the switch so that the top end stop is reached (normalization).
- Then open the window completely so that the lower end stop is reached.
- Then pull the operating switch into the "automatic mode, close" (toll function, close) position and hold it there until the window has reached the top end stop (learning the characteristic curve).

The initialization was successful if the window can be opened and closed without errors in the automatic mode (toll mode).
